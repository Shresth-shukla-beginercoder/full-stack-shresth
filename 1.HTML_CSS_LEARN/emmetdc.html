Example of Emmet shortcuts that help developers write code faster and stay productive:

  • ul>li*5 expands to a list with 5 items. Useful for creating repeated elements quickly.
  • div.container>header+main+footer expands to a page layout structure with three sibling sections. Good for starting a layout skeleton fast.
  • section>article*2>h2+p creates two article sections each with a heading and paragraph. Perfect for repeating content blocks.
  • nav>ul>li*4>a{Item $} generates a navigation menu with 4 links labeled Item 1 through Item 4. Great for prototyping menus.
  • form#contact>label[for=name]{Name}+input#name[type=text]+label[for=email]{Email}+input#email[type=email]+button[type=submit]{Send} expands to a contact form structure. Saves time typing common form markup.

Use > for nesting children, + for siblings, * for multiplication, square brackets for attributes, and braces for inner text. These shortcuts are essential for fast HTML/CSS workflow.

Comments start with <!-- and end with -->.
