CSS3 Box Model and Units

Box Model: width, height, border, border-radius

The CSS box model defines how elements are sized and spaced. The main properties are:

  • width: the content width of the element.
  • height: the content height of the element.
  • border: the line around the padding and content.
  • border-radius: rounds the corners of the border.

Margin and Padding

Margin creates space outside the element. Padding creates space inside the element, between the content and the border.

Display Property

The display property controls how an element is laid out.

  • block: element takes the full width available and starts on a new line.
  • inline: element takes only the width it needs and flows within text.
  • inline-block: behaves like inline but can have width and height.

CSS Units: em and rem

Relative units help create scalable layouts.

  • em: relative to the font-size of the element itself.
  • rem: relative to the font-size of the root element (<html>).

This text is 1.25rem.

This text is 1.2em relative to its parent.

Companies use em and rem for responsive typography and consistent spacing. For example, buttons and cards may use padding: 1rem; and font-size: 1.1rem; so the design scales with user preferences.

How Companies Use These Concepts

In production CSS, teams use these rules to build consistent and responsive layouts:

  • Set base font sizes on the root element and use rem for spacing and typography.
  • Use box-sizing: border-box; so width and height include padding and border.
  • Use margin for spacing between components and padding for internal spacing.
  • Choose display values carefully for layout: block, inline-block, flex, grid, etc.
