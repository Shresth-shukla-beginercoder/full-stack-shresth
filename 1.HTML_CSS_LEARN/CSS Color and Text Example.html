CSS Color and Text Properties

Color vs Background

The color property changes text color. The background (or background-color) property sets the element background.

Example: color: navy; and background: #f4f4f4;

Named Color, RGB, and Hexadecimal

  • color: red; — named color
  • background: rgb(220, 230, 250); — RGB color
  • color: #333333; — hexadecimal color

Use named colors for simple values, RGB when you need red/green/blue numbers, and hex when you want a compact notation for colors.

CSS Syntax Reminder

Every rule uses a property and a value separated by a colon. Each declaration ends with a semicolon. Example: font-family: Arial, sans-serif;

Common Text Properties for Company Web Pages

  • font-family — sets the text font used on the page.
  • font-size — controls size without pixels; use rem or em.
  • line-height — improves readability across paragraphs.
  • color — ensures contrast and brand consistency.

In company design, avoid fixed pixel values. Use 1rem, 1.2rem, or relative units for scalable text size.
