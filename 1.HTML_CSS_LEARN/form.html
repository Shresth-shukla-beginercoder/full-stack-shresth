Basic User Information
Choices and Preferences
Labels: The <label> tag is used to describe a form control. It improves accessibility and makes the form more user-friendly. Clicking the label also focuses the input.
Buttons: The <button> tag creates clickable buttons. Use type="submit" to send the form, type="reset" to clear fields, and type="button" for custom actions.
