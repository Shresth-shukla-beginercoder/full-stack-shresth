Understanding CSS Selectors

Learn the fundamental CSS selectors to target HTML elements effectively.

1. Universal Selector (*)

The universal selector targets all elements on the page. It's often used to reset default styles.

Syntax:
* { margin: 0; padding: 0; }

2. Element Selector

Targets all instances of a specific HTML element.

Syntax:
h1 { color: #333; font-size: 32px; } p { color: #666; }

3. ID Selector (#)

Targets a unique element with a specific ID. Each ID should be used only once per page.

HTML:
<div id="main-content"> Content here </div>
CSS:
#main-content { background-color: white; padding: 30px; }

4. Class Selector (.)

Targets all elements with a specific class. Classes can be reused across multiple elements.

HTML:
<p class="highlight">This is highlighted</p> <p class="highlight">This is also highlighted</p>
CSS:
.highlight { background-color: yellow; color: black; }

5. Descendant Selector (space)

Targets all elements that are descendants of a specified element, at any level.

HTML:
<div class="container"> <p>This paragraph is a descendant</p> <section> <p>This is also a descendant</p> </section> </div>
CSS:
.container p { color: blue; }

6. Adjacent Sibling Selector (+)

Targets an element that comes immediately after another specific element (sibling).

HTML:
<h2>Heading</h2> <p>This paragraph comes right after h2</p>
CSS:
h2 + p { font-weight: bold; }

7. Direct Child Selector (>)

Targets elements that are direct children of a specified element, not nested deeper.

HTML:
<div class="parent"> <p>Direct child</p> <section> <p>Not a direct child</p> </section> </div>
CSS:
.parent > p { color: green; }

8. Attribute Selector ([])

Targets elements based on their attributes. Variations:

Exact Match [attr="value"]:
input[type="text"] { padding: 8px; }
Starts With [attr^="value"]:
a[href^="https"] { color: green; }
Ends With [attr$="value"]:
a[href$=".pdf"] { color: red; }
Contains [attr*="value"]:
a[href*="example"] { text-decoration: underline; }

9. Pseudo-classes (:)

Targets elements based on their state or position. Common pseudo-classes:

Link States:
a:link { color: blue; } a:visited { color: purple; } a:hover { text-decoration: underline; } a:active { color: orange; }
Form States:
input:focus { border: 2px solid blue; } input:disabled { background-color: gray; }
Child Position:
li:first-child { font-weight: bold; } li:last-child { color: red; } li:nth-child(odd) { background-color: #f9f9f9; }

Summary

Universal: * - All elements

Element: element - All of that element type

ID: #id - Unique element by ID

Class: .class - Elements with class

Descendant: parent child - All descendants

Adjacent: element + element - Immediately following sibling

Direct Child: parent > child - Direct children only

Attribute: [attr="value"] - By attributes

Pseudo-class: :state - Based on element state or position
