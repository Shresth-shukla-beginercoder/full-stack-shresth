Quick CSS Concepts

Opacity vs Alpha channel (RGBA)

opacity: makes the whole element (including text/children) translucent. rgba(...,a): only affects the color it is applied to.

opacity 0.5
element opacity
rgba(0,128,128,0.5)
background alpha

Position: static, relative, absolute, fixed

relative sets a new origin for absolute children. absolute positions against nearest positioned ancestor. fixed is relative to viewport.

Short code notes

/* opacity affects whole element: */
.box.opacity{ opacity:0.5 }

/* rgba affects only color channel: */
.box.rgba{ background:rgba(0,128,128,0.5) }

/* transform + transition example */
.btn{ transition: transform .28s cubic-bezier(.2,.9,.3,1) }
.btn:hover{ transform: translateY(-6px) rotate(-2deg) scale(1.04) }
