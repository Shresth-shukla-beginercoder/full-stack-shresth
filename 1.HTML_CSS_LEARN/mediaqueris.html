What is Flexbox?

Flexbox is a CSS layout mode that makes it easier to design flexible and responsive layouts. It works by turning a container into a flex container and its children into flex items.

Example:

 .container {
    display: flex;
}

Key Flexbox Properties

flex-direction

Controls the direction of the main axis.

 .container {
    display: flex;
    flex-direction: row; /* row, row-reverse, column, column-reverse */
}

justify-content

Aligns items along the main axis.

 .container {
    justify-content: center; /* flex-start, center, flex-end, space-between, space-around, space-evenly */
}

flex-wrap

Allows items to wrap to the next line if there is not enough space. 

 .container {
    flex-wrap: wrap; /* nowrap, wrap, wrap-reverse */
}

align-items

Aligns items along the cross axis.

 .container {
    align-items: center; /* flex-start, center, flex-end, stretch, baseline */
}

align-content

Aligns wrapped rows within the flex container.

 .container {
    align-content: space-between; /* flex-start, center, flex-end, stretch, space-between, space-around */
}

align-self

Overrides align-items for a single flex item.

 .item-special {
    align-self: flex-end; /* auto, flex-start, center, flex-end, stretch, baseline */
}

flex-basis

Defines the initial main size of a flex item before free space is distributed. 

 .item {
    flex-basis: 200px;
}

flex-grow and flex-shrink

Control how items grow or shrink relative to others.

 .item {
    flex-grow: 1;   /* grow factor */
    flex-shrink: 1; /* shrink factor */
}

flex shorthand

Shorthand for flex-grow, flex-shrink, and flex-basis.

 .item {
    flex: 1 1 200px; /* grow shrink basis */
}
Tip: Use flex: 1 as shorthand for flex: 1 1 0% when you want equal flexible items.

Responsive Design and Media Queries

Responsive design adapts the layout to different screen sizes. Media queries apply CSS only when a condition is met. 

 @media (max-width: 600px) {
    .container {
        flex-direction: column;
    }
}

This example changes the layout on narrow screens, making the flex container stack vertically.

Building a Responsive Navigation

Use a flex container and media queries to change the navigation layout on smaller devices.

 .responsive-nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.menu {
    display: flex;
    gap: 1rem;
}

@media (max-width: 720px) {
    .responsive-nav {
        flex-direction: column;
        align-items: stretch;
    }
    .menu {
        flex-direction: column;
        gap: 0.5rem;
    }
}

The nav switches from a horizontal menu to a vertical stacked menu on screens smaller than 720px.
