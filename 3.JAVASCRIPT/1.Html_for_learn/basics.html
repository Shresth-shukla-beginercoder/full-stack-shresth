01

The Console & JavaScript Primitives

  • The console is a tool built into every browser (DevTools → Console tab) that shows messages your JS code prints — used constantly for debugging.
  • console.log() prints normal info; console.warn() prints a yellow warning; console.error() prints a red error.
  • A primitive is the most basic kind of value in JS — it's not an object and has no methods of its own. There are 7: number, string, boolean, undefined, null, bigint, symbol.
  • typeof tells you which primitive type a value is.

02

JavaScript Numbers

  • JS has only one number type — no separate "int" or "float". Both 10 and 10.5 are just number.
  • Supports all arithmetic: + - * /, % (remainder/modulo), and ** (exponent).
  • NaN ("Not a Number") appears when a math operation fails, e.g. "abc" * 2.
  • Number("5") converts a string to a number; String(5) does the reverse.
example.js
console.log(10 + 5);
console.log(10 % 3); // remainder
console.log(2 ** 4);  // exponent
console.log(Number('25') + 5);
console.log('abc' * 2); // NaN
03

Variables & Naming Conventions

  • A variable is a named box that stores a value. Declare with let, const, or the older var.
  • let — value can change later. const — value can never be reassigned. var — old-style, function-scoped, avoid in new code.
  • Naming rules: letters, digits, _, $ only; can't start with a digit; case-sensitive.
  • Naming convention: use camelCase (e.g. userAge), give names that describe what's stored, and write CONSTANT_LIKE_THIS for fixed config values.
KeywordReassignable?Scope
letYesBlock { }
constNoBlock { }
varYesWhole function (legacy)
example.js
let userName = 'Shresth';
const birthYear = 2004;
let userAge = 21;
console.log(userName, userAge, birthYear);
04

Updating Variables & Increment/Decrement Operators

  • Reassign a let variable anytime: userAge = 22;
  • Shorthand math-assign operators update in place: +=, -=, *=, /=.
  • x++ (increment) adds 1; x-- (decrement) subtracts 1 — shorthand for x = x + 1.
  • Postfix vs prefix: x++ returns the old value then increments; ++x increments first then returns the new value.
example.js
let score = 10;
score += 5;
console.log(score); // 15
score++;
console.log(score); // 16
let x = 5;
console.log(x++); // 5 (old value)
console.log(x);   // 6
console.log(++x); // 7 (new value)
05

Strings — Indices, Length & Methods (with arguments)

  • A string is text in quotes. Each character has an index starting at 0: "cat"[0] is "c".
  • .length is a property (no parentheses) giving the character count.
  • Common methods that take arguments: .slice(start, end), .toUpperCase(), .toLowerCase(), .includes(text), .replace(old, new), .trim(), .split(separator).
MethodArgument(s)Example → Result
.slice()start, end"hello".slice(1,3) → "el"

.replace()target, replacement"cat".replace("c","b") → "bat"

Connects to HTML: if a page has <input id="name">, then document.getElementById('name').value returns a string — everything typed into an HTML form is a string until you convert it.
example.js
let word = 'JavaScript';
console.log(word[0]);          // 'J'
console.log(word.length);      // 10
console.log(word.slice(0, 4)); // 'Java'
console.log(word.toUpperCase());
console.log(word.includes('Script'));
06

undefined vs null

  • undefined — JS's own default. A variable that's been declared but never given a value is undefined.
  • null — a value you deliberately assign to mean "empty / no value on purpose".
  • Rule of thumb: undefined = "forgotten", null = "intentionally empty".
  • undefined == null is true (loose), but undefined === null is false (strict — different types).
example.js
let a;          // declared, no value
let b = null;  // intentionally empty
console.log(a); // undefined
console.log(b); // null
console.log(a == b);  // true
console.log(a === b); // false
07

Random Numbers & the Math Object

  • Math is a built-in object holding math constants and functions — never needs a new, just call it directly.
  • Math.random() returns a decimal between 0 (inclusive) and 1 (exclusive).
  • To get a random whole number in a range, scale it: Math.floor(Math.random() * (max - min + 1)) + min.
  • Other useful members: Math.round(), Math.floor(), Math.ceil(), Math.max(), Math.min(), Math.abs(), Math.PI.
Connects to HTML: a "random background color" or "shuffle quiz questions" feature on a webpage is just Math.random() feeding into a CSS style or array order.
example.js
console.log(Math.random()); // 0 to <1
let dice = Math.floor(Math.random() * 6) + 1;
console.log('Dice roll:', dice);
console.log(Math.round(4.6));
console.log(Math.max(3, 9, 1));
console.log(Math.PI);

Running JavaScript: Script Tag, alert, prompt, console

  • JS runs on a webpage via <script src="app.js"></script> (external file) or an inline <script>...</script> block, usually right before </body>.
  • alert("message") — pops a blocking dialog box on the page.
  • prompt("question") — pops a dialog with a text input and returns what the user typed as a string (or null if cancelled).
  • console.log() — prints to DevTools only, invisible to a normal visitor; used for debugging, not user-facing messages.

09

Decision Making: Comparison Operators (== vs ===)

  • Comparisons return a boolean: > < >= <= compare size; ==/=== compare equality; !=/!== compare inequality.
  • == (loose equality) converts types before comparing — "5" == 5 is true.
  • === (strict equality) compares value and type, no conversion — "5" === 5 is false.
  • Best practice: always use === and !== to avoid surprising type-conversion bugs.
example.js
console.log(5 == '5');  // true  (loose)
console.log(5 === '5'); // false (strict)
console.log(10 > 3);
console.log(10 !== 10);
console.log(7 >= 7);
10

if / else if / else & Nesting

  • if (condition) { ... } runs the block only when the condition is true.
  • else if checks another condition if the first was false; else catches everything else.
  • Nesting = putting an if inside another if's block, for a condition that only matters once the outer one is true.
Connects to HTML: a form-validation script checks if (email.includes('@')) before letting the HTML <form> submit.
example.js
let marks = 72;
if (marks >= 90) {
  console.log('Grade: A');
} else if (marks >= 75) {
  console.log('Grade: B');
} else if (marks >= 60) {
  console.log('Grade: C');
  if (marks >= 65) { // nested if
    console.log('  (close to a B!)');
  }
} else {
  console.log('Grade: F');
}
11

Truthy & Falsy Values

  • Inside an if, JS converts any value to true or false — even if it's not a boolean.
  • Falsy (there are only 6): false, 0, "" (empty string), null, undefined, NaN.
  • Truthy = everything else, including "0" (a non-empty string!), [], and {}.
example.js
if (0) { ... } else { console.log('0 is falsy'); }
if ('') { ... } else { console.log('empty string is falsy'); }
if ('0') { console.log('"0" the string is truthy'); }
if ([]) { console.log('empty array is truthy'); }
12

Logical Operators: AND, OR, NOT

  • && (AND) — true only if both sides are true.
  • || (OR) — true if at least one side is true.
  • ! (NOT) — flips a boolean: !true is false.
  • Very common for combining conditions: if (age >= 18 && hasID) { ... }.
example.js
let age = 20;
let hasID = true;
console.log(age >= 18 && hasID); // AND → true
console.log(age < 18 || hasID);  // OR  → true
console.log(!hasID);                // NOT → false
13

The switch Statement

  • switch compares one value against several possible cases — a cleaner alternative to a long if/else if chain.
  • Each case needs break, or execution "falls through" into the next case.
  • default runs when no case matched — like a final else.
  • switch compares with strict equality (===) internally.
example.js
let day = 3;
switch (day) {
  case 1: console.log('Monday'); break;
  case 2: console.log('Tuesday'); break;
  case 3: console.log('Wednesday'); break;
  default: console.log('Some other day');
}
14

Arrays — Introduction & Indices

  • An array stores an ordered list of values in one variable: let fruits = ['apple', 'banana', 'mango'];
  • Items are accessed by a zero-based index: fruits[0] is 'apple'.
  • .length gives the number of items; the last item is always arr[arr.length - 1].
  • Arrays can mix types and even hold other arrays or objects.
Connects to HTML: a to-do list app stores tasks in an array, then loops over it with .forEach() to build <li> elements on the page.
example.js
let fruits = ['apple', 'banana', 'mango'];
console.log(fruits[0]);
console.log(fruits.length);
console.log(fruits[fruits.length - 1]); // last item
15

Array Methods

  • .push(x) adds to the end; .pop() removes from the end.
  • .unshift(x) adds to the start; .shift() removes from the start.
  • .concat(arr2) joins two arrays into a new one, without changing the originals.
  • .indexOf(x) returns the position of x, or -1 if not found. .includes(x) returns true/false.
  • .reverse() flips the order in place. .slice(start, end) copies a range without changing the original. .splice(start, deleteCount, ...items) removes/inserts and does change the original.
MethodChanges original?What it does
push / pop / shift / unshift / spliceYesMutates the array directly
slice / concat / indexOf / includes / reverse*slice/concat/indexOf/includes: Noreverse mutates in place too
example.js
let nums = [1, 2, 3];
nums.push(4);      // [1,2,3,4]
nums.unshift(0);   // [0,1,2,3,4]
console.log(nums);
nums.pop();       // removes last
console.log(nums.indexOf(2));
console.log(nums.includes(99));
console.log(nums.slice(1, 3)); // copy, original untouched
nums.splice(1, 1, 'X', 'Y'); // remove 1, insert 2
console.log(nums);
16

Arrays Are Reference Types + Multidimensional Arrays

  • Primitives (number, string, boolean) are copied by value. Arrays and objects are copied by reference — a variable holds a pointer to the same data in memory.
  • So let b = a; does not clone array a — both names point to the same array, and changing one changes the other.
  • To test if two arrays are "equal" in content (not identity), compare element by element or use JSON.stringify() — === only checks if they're the exact same reference.
  • A multidimensional array is an array of arrays — e.g. a grid or matrix: arr[row][col].
example.js
let a = [1, 2, 3];
let b = a;       // b points to the SAME array
b.push(4);
console.log(a); // [1,2,3,4] — a changed too!
console.log(a === b); // true, same reference
console.log(JSON.stringify(a) === JSON.stringify([1,2,3,4]));

let grid = [[1,2,3],[4,5,6],[7,8,9]];
console.log(grid[1][2]); // row 1, col 2 → 6
