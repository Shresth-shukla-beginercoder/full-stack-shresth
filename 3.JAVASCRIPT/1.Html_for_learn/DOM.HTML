1. Introduction to the DOM

  • The DOM (Document Object Model) is a tree-like representation of your HTML page, built by the browser.
  • Every tag becomes a node (object) that JavaScript can read and change.
  • document is the root object — your entry point into the whole page.
  • Changing the DOM changes what's on screen immediately — no page reload needed.
  • This is how buttons, forms, animations, and dynamic apps all work.

2. document.getElementById()

  • Selects one element by its unique id attribute.
  • Returns a single element (or null if not found) — never a list.
  • Fastest and most common way to grab a specific element.
  • Syntax: document.getElementById("idName")

Live Example

Target box (id="idBox")
document.getElementById("idBtn").addEventListener("click", () => {
  document.getElementById("idBox").style.background = "orange";
});

3. getElementsByTagName() & getElementsByClassName()

  • getElementsByTagName("tag") returns a live HTMLCollection of all matching tags.
  • getElementsByClassName("class") returns a live HTMLCollection of all elements with that class.
  • "Live" means the collection auto-updates if the DOM changes later.
  • You must loop through the collection to act on every item (or convert to an array).
  • Syntax: document.getElementsByTagName("li"), document.getElementsByClassName("card")

Live Example

  • Apple
  • Banana
  • Carrot
document.getElementById("tagBtn").addEventListener("click", () => {
  const fruits = document.getElementsByClassName("fruit");
  for (let i = 0; i < fruits.length; i++) {
    fruits[i].style.color = "green";
  }
});

4. querySelector() & querySelectorAll()

  • Both accept any valid CSS selector — id (#), class (.), tag, attribute, nested selectors, etc.
  • querySelector() returns the first matching element only.
  • querySelectorAll() returns a static NodeList of all matches (doesn't auto-update).
  • NodeLists support .forEach() directly — no manual index loop needed.
  • More flexible than getElementById/ClassName because selectors can be complex, e.g. "ul li:first-child".

  document.querySelectorAll(".card").forEach(card => {

5. innerHTML vs textContent vs innerText

  • innerHTML — reads/writes content as HTML (tags get parsed and rendered). Risky with user input (XSS).
  • textContent — reads/writes content as plain text, including hidden elements. Fast, safe.
  • innerText — like textContent, but aware of CSS (ignores hidden elements, respects styling like line breaks).
  • Rule of thumb: use textContent for plain text, innerHTML only when you deliberately need to insert markup.

Live Example

Original content
target.innerHTML = "<strong>Bold via innerHTML</strong>";
target.textContent = "<strong>Not bold — shown as text</strong>";

6. Manipulating Attributes

  • getAttribute("name") — reads an attribute's value.
  • setAttribute("name", "value") — sets/creates an attribute.
  • removeAttribute("name") — deletes it.
  • hasAttribute("name") — returns true/false.
  • Common attributes to manipulate: src, href, alt, disabled, custom data-* attributes.

Live Example

document.getElementById("attrBtn").addEventListener("click", () => {
  document.getElementById("attrImg").setAttribute("src", "https://placehold.co/80x80/6c5ce7/fff");
});

7. Changing Styles with JavaScript

  • element.style.property sets inline CSS directly (camelCase, e.g. backgroundColor).
  • Good for one-off, dynamic changes (based on user actions, calculations, etc).
  • For anything reusable, prefer toggling a CSS class instead (see classList next).
  • getComputedStyle(element) reads the final, rendered style (including from CSS files).

Live Example

document.getElementById("styleBtn").addEventListener("click", () => {
  const box = document.getElementById("styleBox");
  box.style.background = `hsl(${Math.random()*360}, 70%, 60%)`;
  box.style.borderRadius = Math.random()*50 + "px";
});

8. classList

  • classList.add("name") — adds a class.
  • classList.remove("name") — removes a class.
  • classList.toggle("name") — adds it if missing, removes it if present.
  • classList.contains("name") — returns true/false.
  • Preferred over inline .style for anything reusable — keeps styling in CSS, logic in JS.

Live Example

Toggle me
document.getElementById("classBtn").addEventListener("click", () => {
  document.getElementById("classBox").classList.toggle("active");
});

9. Traversing the DOM (Parent / Child / Sibling)

  • parentElement — the direct parent node.
  • children — an HTMLCollection of direct child elements.
  • firstElementChild / lastElementChild — first/last child element.
  • nextElementSibling / previousElementSibling — neighbor elements at the same level.
  • These all skip text/whitespace nodes — they only return real elements.

document.getElementById("travBtn").addEventListener("click", () => {
  const parent = document.getElementById("parentLi");
  [...parent.querySelector("ul").children].forEach(c => c.style.color = "crimson");

10. append(), appendChild(), remove(), removeChild()

  • document.createElement("tag") — makes a new element in memory (not on screen yet).
  • parent.appendChild(node) — adds a node as the last child (classic, one node only).
  • parent.append(...) — modern version; accepts multiple nodes and plain text strings.
  • element.remove() — removes the element itself directly. Simplest way to delete.
  • parent.removeChild(node) — older syntax; parent must remove its own child explicitly.

Live Example

document.getElementById("addBtn").addEventListener("click", () => {
  const li = document.createElement("li");
  li.textContent = "New task " + Date.now() % 1000;
  document.getElementById("taskList").appendChild(li);
});

11. Final Demo — Mini Pokédex

This ties everything together in one working feature: createElement, appendChild, setAttribute, classList, textContent, querySelector, and event traversal — all used to render sprite cards and let you search/filter them.

// simplified core logic
pokeList.forEach(p => {
  const card = document.createElement("div");
  card.className = "poke-card";
  card.setAttribute("data-name", p.name);

  const img = document.createElement("img");
  img.src = `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/${p.id}.png`;
  img.alt = p.name;

  const name = document.createElement("p");
  name.textContent = p.name;

  card.append(img, name);
  card.addEventListener("click", () => card.classList.toggle("caught"));
  pokeGrid.appendChild(card);
});
