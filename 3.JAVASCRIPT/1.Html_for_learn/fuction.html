JavaScript Functions

Click each "Run" button to see the concept in action. Open the browser console too (F12) — most demos also log there.

1. Intro to Functions — Your First Function

A function is a reusable block of code that runs when you "call" it.

function greet() {
      document.getElementById("out1").textContent = "Hello!";
    }

    greet();

2. Arguments — Passing Data In

Arguments let you send values into a function so it can use them.

function greetPerson(name) {
      document.getElementById("out2").textContent = `Hello, ${name}!`;
    }

    greetPerson("Shresth");

3. Function with Multiple Arguments

A function can accept more than one piece of data at once.

function addNumbers(a, b) {
      document.getElementById("out3").textContent = a + b;
    }

    addNumbers(7, 5);

4. The return Keyword

return sends a value back out of the function, so you can store or reuse it.

function square(number) {
      return number * number;
    }

    const result = square(6); // 36

5. Function Scope

Variables declared with var/let/const inside a function only exist inside that function.

function demoFunctionScope() {
      const message = "I'm inside the function";
      console.log(message);
    }

    demoFunctionScope();

6. Block Scope

let and const are confined to the nearest { } block, e.g. an if or a loop.

if (true) {
      let message = "I'm inside this block";
      console.log(message);
    }
    // message is not available here

7. Lexical Scope

An inner function can "see" the variables of the function it's physically written inside, based on where it's defined — not where it's called.

function outer() {
  const message = "From the outer function";

  function inner() {
    return message; // sees outer's variable
  }

  return inner();
}

8. Function Expressions

A function stored inside a variable, instead of declared with the function keyword on its own.

const multiply = function (a, b) {
      return a * b;
    };

    multiply(4, 3); // 12

9. Higher Order Functions

A function that takes another function as an argument, or returns one.

function calculate(a, b, operation) {
      return operation(a, b);
    }

    calculate(7, 5, (x, y) => x + y); // 12

10. Returning a Function (Closures)

A function can build and return another function, which "remembers" the variables around it.

function makeGreeter(name) {
  return function () {
    return `Hello, ${name}!`;
  };
}

const greetShresth = makeGreeter("Shresth");
greetShresth(); // "Hello, Shresth!"

11. Defining Methods

A method is simply a function stored as a property of an object.

const person = {
  name: "Shresth",
  greet() {
    return `Hello, ${this.name}!`;
  }
};

person.greet();
