Bootstrap Examples — Extended

This page walks through Bootstrap 4 components step by step. Each section has point-wise notes above it so you know WHAT the component is, WHY you'd use it, and WHICH classes matter most.

1. Containers

Points to remember:
  • .container = fixed max-width, centered, responsive padding.
  • .container-fluid = always 100% width (edge to edge).
  • Containers are the outermost wrapper — everything else (rows, columns) goes inside them.

.container — notice it stops before the edges of the screen.

2. Grid System (Rows & Columns)

Points to remember:
  • Grid = 12 columns total per .row.
  • .col-md-6 means "take 6 of 12 columns on medium screens and up" = half width.
  • On small screens, columns you didn't set a breakpoint for stack full-width automatically (mobile-first).
  • Breakpoints: sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px).

3. Typography

Points to remember:
  • .lead = makes a paragraph stand out (slightly bigger, lighter weight).
  • .text-muted, .text-primary, .text-success etc. = color utilities for text.
  • .font-weight-bold / .font-italic = quick text styling without custom CSS.

4. Buttons & Button Groups

Points to remember:
  • .btn is required on every button; then add a color like .btn-primary.
  • Size modifiers: .btn-sm (small), .btn-lg (large), default = medium.
  • .btn-outline-* = hollow button style.
  • .btn-group = groups multiple buttons together with no gaps.

9. Forms

Points to remember:
  • .form-group wraps a label + input pair.
  • .form-control = styled input/select/textarea.
  • .form-check = wrapper for checkboxes/radios.

10. Collapse & Accordion (JS powered)

Points to remember:
  • data-toggle="collapse" + data-target="#id" = show/hide a section on click.
  • This uses Bootstrap's bundled JS (no custom script needed) — great for FAQs.

11. Modal (Popup Window, JS powered)

Points to remember:
  • data-toggle="modal" + data-target="#modalId" opens the modal.
  • Modal structure: .modal → .modal-dialog → .modal-content → header/body/footer.

12. Tooltips & Popovers (JS powered)

Points to remember:
  • Tooltips/popovers need a small JS line to "activate" them — see the script at the bottom of this file: $('[data-toggle="tooltip"]').tooltip().
  • title="..." attribute holds the tooltip text.
  • Popovers are like tooltips but can hold more content and stay open until clicked away.

13. Tabs (JS powered)

Points to remember:
  • .nav-tabs + data-toggle="tab" = clickable tab headers.
  • Each tab link's href="#id" must match the target pane's id.

14. Progress Bars (JS updated)

Points to remember:
  • .progress = outer track; .progress-bar = filled inner bar.
  • Width is set via inline style="width: X%" — JS can change this dynamically.

16. Utilities

Points to remember:
  • .text-center, .text-right, .text-left = text alignment.
  • .d-flex, .justify-content-between = flexbox utilities (useful since you're already studying flexbox!).
  • .m-* / .p-* = margin/padding shortcuts (e.g. .p-3 = padding level 3).
